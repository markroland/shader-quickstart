# Shader Quickstart using standard HTML, JavaScript and WebGL (script tags)

## Run

Use Node:

```
npx http-server ./src
```

## Information

This is the same as `vanilla-webgl`, however instead of enclosing the shader code
in a template literal, the shader code is wrapped in a `<script>` tag with the
`x-shader` MIME type. Both approaches are equally valid.
